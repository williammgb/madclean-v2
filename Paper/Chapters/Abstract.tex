\chapter*{Abstract}
High-quality data is essential for effective decision-making, data analytics and the training of machine learning models. 
However, real-world tabular datasets frequently contain errors, inconsistencies and missing values that degrade data quality and hinder downstream tasks. 
While numerous data cleaning methods have been proposed, many suffer from limited flexibility and adaptability across datasets and struggle to effectively handle semantic errors. 
Recent approaches leveraging Large Language Models (LLMs) address these limitations by enabling more flexible and context-aware cleaning, but often lack robustness guarantees, leading to unreliable or inconsistent results. 
This thesis presents an automated tabular data cleaning framework that integrates statistical data profiling with the semantic reasoning and code generation capabilities of LLMs. 
Statistical profiling is used to extract dataset characteristics and relationships that guide the LLM in selecting appropriate cleaning operations. 
A multi-agent LLM architecture generates executable cleaning logic to ensure scalable and consistent data cleaning, while validation mechanisms are employed to verify correctness and improve reliability. 
Experimental results demonstrate that the framework achieves strong cleaning performance with competitive runtime, achieving near-one F1 scores on three of the four benchmark datasets, enabling automated and adaptive data cleaning and producing high-quality tabular data suitable for downstream analytical and machine learning tasks.
